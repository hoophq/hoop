Control plane deployed.

  kubectl logs deploy/{{ include "hoopcontrolplane.fullname" . }}
{{- if .Values.service.enabled }}
  kubectl port-forward svc/{{ include "hoopcontrolplane.fullname" . }} 8009:8009
{{- else }}
  kubectl port-forward deploy/{{ include "hoopcontrolplane.fullname" . }} 8009:8009
{{- end }}

Confirm it answers:

  curl -s http://127.0.0.1:8009{{ include "hoopcontrolplane.basePath" . }}/api/healthz

This is the gateway. Only HTTP 8009 is published; gRPC on :8010 stays inside
the pod. Sidecars need nothing else.

Register a sidecar at {{ .Values.config.API_URL }}, copy the token it shows
once, and install hoopsidecar-chart with controlPlane.url and
controlPlane.token.

Documentation: https://hoop.dev/docs/setup
